Argos — 웹 취약점 자동 진단 플랫폼

2026.07·7인 팀 (팀명: 너의 취약점은)·인프라 팀장
SK쉴더스 루키즈 5기 최종프로젝트 대상

URL/IP를 스캔해 KISA/SK 보안 가이드라인 기준의 컴플라이언스 진단 보고서를 자동 생성하는 SaaS. 인프라 작업을 6개 모듈(네트워킹 / 프론트엔드·백엔드 컴퓨팅 / 스토리지 / CI / CD)로 나눠 팀원을 배정하고 PR 리뷰와 코드 통합을 담당했습니다.

인프라 개선
  • 최신 AMI 조회 방식이 AWS 패치 AMI 릴리스 시 인스턴스를 재생성해 다운타임을 유발하던 문제 확인
  • lifecycle { ignore_changes = [ami] } 설정으로 해결
배포 보안 개선
  • GitHub Actions Repository Variables에 평문 노출된 인스턴스 ID, ECR 레지스트리 주소, 서비스 도메인 등 4개 설정값 확인
  • 해당 설정값을 전부 Secrets로 전환
